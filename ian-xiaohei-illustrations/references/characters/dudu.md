# Dudu — West African / Afrofuturist

## Visual Descriptors

- Sleek, elongated black form — taller and more vertical than Xiaohei
- White geometric eye: diamond or upward-pointing triangle shape
- Arms can extend and morph into the tool itself (arm = lever, arm = funnel, arm = path)
- Body morphs: Adinkra symbol silhouette, calabash form, kente-strip-wrapped block, woven-basket cross-section
- Adinkra symbol line quality — confident, geometric, each mark carries meaning
- Clean edges, no ink bleed — precision of a carved stamp

## Personality

- Ancient rhythm meets futuristic system
- Operating the machine in time with something older than the machine
- Wisdom-worker: doing the task because it fits into a larger pattern only visible from far above
- Arms become tools — no separation between the worker and the work
- Unhurried because the outcome is already known
