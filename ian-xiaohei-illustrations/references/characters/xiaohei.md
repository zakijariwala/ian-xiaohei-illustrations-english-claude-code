# Xiaohei — Chinese / East Asian

## Visual Descriptors

- Solid black ink-blob body, slightly irregular hand-drawn outline
- White circular dot eyes
- Thin legs, occasionally thin arms
- Body morphs freely: cylindrical, bean-shaped, black box, funnel, shadow, hole entrance, dark block inside a machine
- Ink-brush stroke quality — like a seal stamp or ink drop with limbs

## Personality

- Deadpan, serious, never cute
- Low-profile system operator
- A little clumsy, but competent
- Doing something absurd but fully coherent
- Like a factory worker assigned to a cosmically pointless but essential task
