# Composition Patterns and Originality Rules

## Basic Structure Types

Pick one — don't mix too many.

### Workflow

Best for: input → process → output, content production, AI workflows, automation pipelines.

How to draw: input on the left, Xiaohei or a strange machine processing in the middle, output on the right, orange arrows showing the main direction.

### System Slice

Best for: information sources, filters, databases, renderers, partial views of an agent system.

How to draw: only 3–5 core modules, Xiaohei participates in one key action.

### Before / After Contrast

Best for: chaos/order, manual/automated, scattered/consolidated, anxious/stable.

How to draw: chaos on the left, stable on the right, orange arrow in the middle. Characters can be more exaggerated.

### Character State

Best for: user pain points, creator states, too many tools, information anxiety, stuck vs. moving.

How to draw: 2–4 small states, one short annotation per state.

### Conceptual Metaphor

Best for: content factory, information warehouse, mental black box, workflow machine, auto-report.

How to draw: one large strange object or machine, minimal input, one output. Needs a memorable hook.

### Method Layers

Best for: methodology frameworks, system layers, capability stacks, content system tiers.

How to draw: stacked boxes, not a formal pyramid; Xiaohei carrying bricks or building on the side.

### Map / Route

Best for: idea to launch, user path, content handoff path, learning route.

How to draw: one winding path, few nodes, Xiaohei pulling a wire or walking.

### Mini Comic Panels

Best for: failure to success, real process, complaint format, before/after usage.

How to draw: 2–4 small panels, each expressing only one action.

## Original Metaphor Generation

Invent a fresh metaphor from the current article every time — never copy old images.

### Three Steps

1. Replace the abstract concept with a physical action: stuck, leaking, getting heavier, sorting, settling, fermenting, opening a door, folding, unwrapping, flowing back.
2. Replace the system structure with a low-tech object: a broken machine, a cardboard box, a drawer, a pipe, a mailbox, a weird gauge, a scale, a well, a ladder, a strange workstation.
3. Let Xiaohei carry the action: not standing nearby, but stuck inside the machine, pulling the wrong wire, guarding the gate, hauling, patching, weighing, steadying the ladder, recording, stuffing things into some strange contraption.

### Object Pool

- Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, pipe, ball of wire, sluice gate, spinning dial, black box, hole punch, pasta press, clothesline, strange workstation.
- When using, pick only 1–2 — don't pile them up.

### Xiaohei Action Pool

- Pull, carry, stuff, scoop, press, weigh, sew, cut, twist, guard, push, catch, disassemble, mark, recycle.
- The action should serve the core meaning — don't be weird just for the sake of it.

## Anti-Reuse Rules

Don't open or recreate `assets/examples/` by default. Those images are only for visual calibration — line density, blank space, color restraint, Xiaohei's energy level.

Unless the user explicitly says "based on this one / recreate this composition / modify this example," never directly reuse these old compositions:

- Conveyor belt with two breakpoints
- Xiaohei pulling the judgment lever inside a content machine
- Xiaohei becoming a funnel sorting traffic/trust/conversions
- Xiaohei slicing the material fish
- Xiaohei holding the handoff path
- Xiaohei pulling three-layer information sources
- Three Xiaoheis holding a megaphone / building a bridge / opening a door
- Xiaohei stamping the phrase toolbox
- Xiaohei holding a sign watching the common-pitfall path

Same theme — still invent a new metaphor. For example, "handoff path" doesn't have to be a road — it could be Xiaohei attaching the content's tail to a door handle. "One-to-many reuse" doesn't have to be a fish — it could be Xiaohei pressing a paper ball into several shapes.
